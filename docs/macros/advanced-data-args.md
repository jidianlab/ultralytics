| Argument              | Type   | Default | Description                                                                                                                                                                                             |
| --------------------- | ------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `label_aliases`       | `dict` | `None`  | Mapping of target class names to lists of source label names. Allows merging multiple dataset labels into unified classes (e.g., `{person: [human, pedestrian], vehicle: [car, truck]}`).              |
| `class_augmentations` | `dict` | `None`  | Per-class augmentation parameters. Each class can have custom augmentation settings applied only to its pixel regions (e.g., `{person: {hsv_h: 0.02, region_expand: 0.1}}`).                            |
| `region_expand`       | `float`| `0.0`   | Expansion amount for per-class augmentation regions. Values < 1.0 are treated as ratios (e.g., 0.1 = 10% expansion), values >= 1.0 are treated as pixels. Expansion stops at image edges or other objects. |
