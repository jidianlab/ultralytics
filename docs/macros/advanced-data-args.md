| Argument              | Type   | Default | Description                                                                                                                                                                                             |
| --------------------- | ------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `label_aliases`       | `dict` | `None`  | Mapping of target class names to lists of source label names. Allows merging multiple dataset labels into unified classes (e.g., `{person: [human, pedestrian], vehicle: [car, truck]}`).              |
| `class_augmentations` | `dict` | `None`  | Per-class augmentation parameters. Each class can have custom augmentation settings applied only to its pixel regions, including a `region_expand` sub-parameter for region expansion (e.g., `{person: {hsv_h: 0.02, region_expand: 0.1}}`). Values < 1.0 are treated as ratios, values >= 1.0 are treated as pixels. Expansion stops at image edges or other objects. |
